# MUTOSHOP

AI 자동 누끼와 색감 보정에 집중한 사진 편집 프로그램입니다. 모든 처리는 이 PC 안에서만 이루어지고, 사진이 외부로 나가지 않습니다.

## 실행

**바탕 화면의 MUTOSHOP 아이콘**(또는 `start.bat`)을 더블클릭하면 프로그램 창이 열립니다.

- 처음 실행할 때는 필요한 구성요소를 자동으로 설치합니다(인터넷 필요).
- 검은 콘솔 창은 프로그램 본체(이 PC 안에서만 도는 로컬 서버)입니다. **이 창을 닫으면 프로그램이 종료**됩니다. 업데이트 뒤에는 이 창을 닫고 다시 실행하세요.
- 이미 실행 중일 때 다시 더블클릭하면 창만 하나 더 열립니다.

## 주요 기능

### 누끼 (배경 제거)
누끼 탭에서 **무엇을 따는지 고르고 → 누끼 따기** 버튼 하나면 됩니다.

| 종류 | 이런 그림에 | 객체를 지키는 방식 |
|---|---|---|
| **나무** | 나무·숲·풀·꽃 | 잎·가지 사이로 비치는 배경(배경과 미묘하게 다른 하늘색까지)도 지우고, 흰 꽃처럼 둘레가 옅은 부분은 남깁니다. AI 를 쓰지 않아 장당 1초 안팎. |
| **산** | 산·바위·지형·건물 | 눈 덮인 봉우리·밝은 바위도 산의 일부로 지킵니다. |
| **아이템** | 칼·방패·아이콘·스프라이트 | 흰 칼날·보석처럼 배경과 비슷한 색도 아이템 안쪽이면 지우지 않습니다. 윤곽선이 조금 끊겨 있거나 칼끝이 사진 테두리에 닿아도 안쪽으로 배경이 스며들지 않습니다. |
| **인물** | 사람·캐릭터 | 사람·캐릭터 모양을 지키고, 사진이면 인물 전용 AI 로 머리카락까지 땁니다. |

- **배경이 한 가지 색에 가까운 그림** (흰색·민트·하늘색·크림·어두운 색 등, 미묘한 차이·그라데이션 포함): 배경색을 자리마다 읽어서 **색으로 정확히** 땁니다. 경계는 픽셀 단위로 또렷하고, 섞인 배경색을 정확히 빼서 새 배경 위에서 흰 테두리가 뜨지 않습니다.
  - 산·아이템·인물은 가벼운 도우미 AI(ISNet, 178MB, CPU)로 배경과 같은 색인 객체 부분을 한 번 더 확인해 지킵니다 (처음 한 번 자동으로 내려받음). GPU 를 쓰지 않아 메모리를 1GB 안쪽으로 씁니다.
  - 메모리가 아주 모자라면 AI 확인 없이 색으로만 따고 알려 줍니다.
- **사진** (배경이 여러 색): BiRefNet AI 가 피사체를 찾습니다 (인물은 인물 모델). 정밀 2단계 분석.
- **고급 설정** (누끼 탭 아래, 접혀 있음)
  - *피사체 안쪽의 배경색*: **종류대로**(기본) / **남기기**(안쪽은 하나도 안 지움) / **지우기**(피사체에 둘러싸인 배경색·하늘 조각을 모두 지움, 작은 하이라이트 점은 남김). 나무 사이 하늘 조각이 남으면 *지우기*로 다시 따 보세요.
  - *머리카락 최고 품질* (인물일 때만): 사진의 경계를 원본 해상도로 한 번 더 분석합니다. 훨씬 느리고 메모리를 많이 써서 기본은 꺼짐.
  - 가장자리(부드럽게·경계 대비·가장자리 이동), 흰 테두리 한 번에 제거, 테두리 색, 마스크 반전
- **배경 찍기** (`G`, 왼쪽 도구 막대 · 누끼 탭 버튼): 지울 배경을 클릭하면 **그곳과 이어진 배경만** 지웁니다 (마술봉처럼 원하는 곳만, 경계는 누끼 엔진 방식으로 깨끗하게 · 흰 테두리 없음).
  - 누끼 없이 바로 찍으면 찍은 곳만, 자동 누끼 뒤에 찍으면 그 결과에 더해 지웁니다 (고리 안쪽 같은 남은 구멍). 찍을 때마다 다시 따므로 `Ctrl+Z`로 한 번씩 되돌릴 수 있고, *처음부터*로 다시 시작합니다.
  - 윤곽선이 조금 끊긴 곳으로는 새지 않고, 아이템·산·인물은 AI가 객체(윤곽선 없는 흰 칼날 등)를 한 번 더 지킵니다.
- **결과 확인 보기**: 합성 / 오버레이(지워진 곳 빨간색) / 마스크 / 검정 배경 / 흰 배경. `F` 키로 전환합니다.
- **브러시로 다듬기**: 복원(B) / 지우기(E). 크기·경도·불투명도·자동 경계는 위쪽 옵션 막대에 있습니다.
- **외곽선**: 마스크 윤곽을 따라 원하는 색·두께의 선을 그립니다 (포토샵 레이어 스타일의 ‘획’과 같음).
- **테두리 깎기**: 누끼 탭 보기 버튼 아래 ⊟ / ⊞ — 피사체 바깥 테두리를 **1px 씩** 깎습니다 (Shift 5px, 최대 50px). 외곽선을 너무 두껍게 넣어 저장한 투명 PNG 를 열어 깎으면 선이 그만큼 얇아집니다. 사진 가장자리에 닿은 부분은 깎지 않고, 깎은 폭보다 가는 부분(1~2px 선 등)은 함께 사라질 수 있으니 화면으로 확인하세요.
  - 색 칸(없음·흰색·검정·빨강·주황·노랑·초록·파랑·보라)을 누르면 바로 켜지고, 두께는 기본 **2px · 가운데**.
  - *더보기*: 색 직접 지정, 위치(바깥 / 가운데 / 안쪽), 부드럽게, 불투명도, 그라디언트(가장 바깥 색 → 안쪽 색).
  - 잔가지·털이 많은 피사체에 두꺼운 *바깥* 선을 넣으면 틈이 메워집니다. 두께를 줄이거나 *안쪽*을 쓰세요.

### 폴더 열기 (하나씩 직접 작업)
위쪽 **폴더 열기** 버튼 (`Ctrl+Shift+O`). 폴더를 고르면 맨 위에 사진들이 **필름 줄**로 나옵니다.
- 사진을 누르면 편집기에서 열립니다. `PageUp` / `PageDown` 으로 이전·다음, *안 한 것* 으로 아직 안 한 다음 사진.
- 작업한 뒤 **`Ctrl+S`** (또는 필름 줄의 *저장*) → 고른 폴더 안의 `누끼` 폴더에 PNG 로 바로 저장 (저장 창 없음, 원본은 그대로).
- 저장한 사진은 **초록 체크(완료)** 로 표시되고, *저장 후 다음* 을 켜 두면 안 한 다음 사진이 바로 열립니다. 다시 열어도 `누끼` 폴더에 결과가 있는 사진은 완료로 나옵니다.

### 폴더 작업 (일괄 누끼)
위쪽의 **폴더 작업** 버튼(또는 파일 › 폴더 작업)으로 폴더 안의 사진을 한 번에 처리합니다. **원본은 그대로 두고 결과는 복사본으로** 저장합니다.

1. **폴더**: *찾아보기*로 고르거나 경로를 붙여넣기. *하위 폴더까지 포함*을 켜면 폴더 구조 그대로 결과를 만듭니다.
   - 저장 위치 기본값은 고른 폴더 안의 `누끼` 폴더. *변경*으로 다른 곳을 고를 수 있습니다.
2. **종류**: 나무 / 산 / 아이템 / 인물 (편집기와 같은 방식). 종류가 섞인 폴더는 나눠서 돌리면 가장 깨끗합니다.
3. **외곽선**: 색 칸 + 두께. *더보기*에 위치 · 부드럽게 · 불투명도 · 그라디언트, 두께 단위(**px** 또는 사진 긴 변 기준 **%**). *편집기 설정 가져오기*로 편집 중인 외곽선 설정을 그대로 쓸 수 있습니다.
4. **저장**: 저장 위치와 한 줄 요약 (기본: PNG · 투명 배경 · 원본 크기).
   - *고급 설정*: 하위 폴더 포함, 이미 만든 결과 건너뛰기(중간에 멈췄다 이어서), 이미 투명한 PNG 는 그대로, 안쪽 배경색·최고 품질, 배경(투명/단색), 형식(PNG/WEBP/JPG)·품질, 크기, 피사체 배치(그대로/딱 맞게 자르기/정사각형 중앙 + 여백), 파일 이름 뒤에 붙일 말.
   - 투명 PNG·WEBP 는 투명한 픽셀에도 가장자리 색을 채워 저장해서, 게임 엔진에서 축소해도 흰 테두리가 비치지 않습니다.

- 처리는 **서버(검은 창)가 한 장씩** 합니다 (읽기 → 누끼 → 외곽선·배경 → 저장). 화면은 진행 상황만 보여 줘서, 큰 사진 수백 장도 메모리를 적게 씁니다. 진행 상황·남은 시간이 보이고, 언제든 *중지*할 수 있습니다.
- 끝나면 *결과 폴더 열기*, 실패·중지된 것만 *남은 것 다시*.
- 처리 중에는 PC가 절전 모드로 들어가지 않습니다.
- 이름만 같고 확장자가 다른 파일(a.jpg, a.png)은 `a_jpg.png`, `a_png.png`처럼 구분해서 저장합니다. 원본 파일을 덮어쓰는 일은 없습니다.

### 직접 따기 (포토샵 도구)
왼쪽 도구 막대에 있습니다. 포토샵과 같은 방식입니다. **영역을 선택 → `Delete`로 지우기, 또는 `Ctrl+J`로 선택한 부분만 남기기.**

| 도구 | 키 | 사용법 |
|---|---|---|
| 펜 | `P` | 클릭=직선 점, 드래그=곡선 점, 첫 점 클릭=닫기. 점·핸들은 끌어서 수정(Alt: 핸들 따로). `Enter`=선택 영역으로, `Backspace`=마지막 점 삭제 |
| 올가미 / 다각형 올가미 | `L` | 자유: 드래그로 그리기 · 다각형: 클릭으로 꼭짓점, 더블클릭이나 첫 점 클릭으로 닫기 |
| 사각형 / 원형 선택 | `M` | 드래그. Shift를 누른 채 끌면 정사각형·정원 |
| 자동 선택 (마술봉) | `W` | 클릭한 곳과 비슷한 색을 선택. 옵션: 허용치, 인접, 앤티 앨리어스 |
| 색 범위 | `C` | 클릭한 색과 비슷한 곳을 **사진 전체에서** 선택 (떨어져 있어도). `Shift`+클릭 색 더하기 → `Delete` 로 지우기 |

- **선택 영역 넓히기·줄이기**: 선택 도구 막대 맨 앞의 ⊟ / ⊞ 버튼 — 누를 때마다 1px, 누르고 있으면 계속 (Shift 5px, 단축키 `Alt+-` / `Alt+=`). 선택 크기(가로×세로)가 옆에 표시됩니다.
- **문질러 빼기** (마술봉·색 범위): 선택한 뒤 사진 위를 **끌어서 문지르면 그 부분이 선택에서 빠집니다** (Shift+끌기는 더하기). 붓 크기는 막대의 *문질러 빼기 붓* 또는 `[` `]`. 클릭은 그대로 색 고르기. 한 번 문지른 게 `Ctrl+Z` 한 단계.
- **마술봉 허용치**: 슬라이더를 끌거나 숫자를 바꾸면 방금 클릭한 영역이 새 허용치로 바로 다시 선택됩니다 (넓히기·줄이기 한 만큼도 유지).
- 그리기 시작할 때 **Shift = 선택에 더하기, Alt = 빼기, Shift+Alt = 겹치는 부분만**
- 선택 영역 처리: **지우기**(`Delete`) / **되살리기**(지워진 부분 복구) / **이것만 남기기**(`Ctrl+J`) / 반전(`Ctrl+Shift+I`) / 전체 선택(`Ctrl+A`) / 해제(`Ctrl+D`)
- AI 누끼 결과를 고칠 때도 같은 방식으로 쓸 수 있습니다. 예: 남은 배경을 올가미로 감싸고 `Delete`.
- **선택도 `Ctrl+Z` 로 한 단계씩** 되돌립니다. 여러 번 더해 선택하다가 `Ctrl+Z` 하면 방금 더한 것만 빠지고, `Ctrl+Shift+Z` 로 다시 넣습니다. 지우기 같은 편집과 섞여 있으면 더 최근에 한 쪽부터 되돌립니다 (⊞ 를 연달아 누른 건 한 단계, 허용치 바꾼 건 그 클릭과 같은 단계).

### 색감
- **필터 15종**: 현재 사진에 적용한 모습을 썸네일로 미리 보여 줍니다.
- **자동 보정**: 노출·대비·화이트밸런스를 자동으로 맞춥니다.
- **빛**: 노출, 밝기, 대비, 하이라이트, 섀도, 흰색 계열, 검정 계열
- **색**: 색온도, 색조, 활기, 채도, 색상 회전
- **컬러 믹서**: 8가지 색상대별로 색상·채도·밝기 조절
- **컬러 그레이딩**: 섀도/중간톤/하이라이트에 색 입히기
- **곡선**: RGB 전체 및 채널별
- **효과**: 부분 대비, 선명하게, 비네팅, 그레인
- 누끼를 딴 뒤에는 **전체 / 피사체만 / 배경만** 따로 보정할 수 있습니다.

### 배경
- 원본 유지 / 투명 / 단색(스포이드로 사진 속 색 고르기 가능) / 흐림(인물 사진 모드 효과) / 다른 사진으로 교체
- **그림자**: 제품 사진을 바닥에 놓인 것처럼 보이게 합니다.

### 그 밖에
- 자르기(비율 고정), 90° 회전, 좌우 반전
- 실행 취소/다시 실행(최근 60단계), 작업 기록에서 원하는 시점으로 이동
- 원본 비교: 버튼을 누르고 있거나 `\` 키, 또는 분할 비교
- 내보내기: PNG(투명 유지) / JPG / WEBP, 크기 지정, **피사체에 딱 맞게 자르기 / 정사각형 중앙 배치**(쇼핑몰 상품 사진용), 클립보드 복사
- 열 수 있는 형식: JPG, PNG, WEBP, HEIC(아이폰 사진), BMP, GIF 등. 끌어다 놓기, `Ctrl+O`, `Ctrl+V` 붙여넣기 모두 됩니다.

| `Ctrl+I` | 마스크 반전 | `F` | 누끼 확인 보기 전환 |
| `C` / `Shift+C` | 색 범위 / 자르기·회전 | `I` | 스포이드(배경색) |
| `\` (누르고 있기) | 원본 보기 | `?` | 단축키 목록 |

슬라이더는 **더블클릭하면 기본값**으로 돌아가고, 숫자를 눌러 직접 입력할 수도 있습니다.

## 누끼를 더 잘 따는 요령

1. 피사체와 배경의 색이 비슷하면 결과를 **오버레이 보기**(`F`)로 확인하고, 모자란 곳은 복원 브러시로 칠하세요.
2. 머리카락 주변은 **자동 경계**를 켠 지우기 브러시로 배경 쪽만 살살 문지르면 머리카락을 건드리지 않고 정리됩니다.
3. 경계가 딱딱해 보이면 *부드럽게(페더)* 를 1~3px 정도 주세요. 배경이 살짝 남으면 *가장자리 이동* 을 −10~−20%로.
4. 나무 사이로 비치는 하늘이 조금 남으면 *고급 설정 › 피사체 안쪽의 배경색 › 지우기*로 다시 따 보세요. 반대로 피사체의 흰 부분이 지워지면 *남기기*.

## 문제 해결

- **누끼가 느리다 (상태바에 'CPU'로 표시)**: NVIDIA 그래픽 드라이버가 설치되어 있는지 확인하세요. GPU가 없거나 인식되지 않으면 CPU로 처리하며 장당 30초 이상 걸립니다.
- **"서버에 연결할 수 없어요"**: 콘솔 창이 닫혔거나 오류가 난 경우입니다. 바탕 화면 아이콘(또는 `start.bat`)으로 다시 실행하세요.
- **설치가 계속 실패한다**: `.venv` 폴더를 지운 뒤 `start.bat` 을 다시 실행하세요.
- **화면이 이상하게 그려진다**: 창을 새로고침(`F5`) 하세요. (편집 내용은 사라집니다)
- GPU 메모리를 많이 쓰는 게임 등을 함께 켜 두면 누끼가 느려질 수 있습니다.
- **메모리 아끼기** (페이지 파일이 작거나 Unity 같은 큰 프로그램을 같이 켜 둘 때를 기준으로 맞춤)
  - 단색 배경 그림(나무·산·아이템·인물)은 GPU AI 를 아예 켜지 않고 1GB 안쪽으로 땁니다.
  - 무거운 작업(누끼·폴더 작업 한 장·사진 열기)은 한 번에 하나씩만 돌아서 메모리를 겹쳐 쓰지 않습니다.
  - 사진 AI(BiRefNet)는 쓰는 동안 모델을 올려 둡니다 (10분 쉬면 내리고, 12분 쉬면 AI 엔진을 끔). 대신 15초마다 메모리 여유를 보고 **1.5GB 밑이면 바로 내려서** 다른 프로그램에 양보합니다.
  - 사진 누끼 직전에 필요한 메모리(처음이면 약 5.4GB, 모델이 올라와 있으면 약 3.5GB)를 확인하고, 모자라면 최대 15초 기다린 뒤(*여유 2.9GB / 필요 4.3GB* 처럼 표시) **메모리 절약 모드**(같은 모델·같은 품질, 느림) → 그래도 모자라면 가벼운 모델로 대신 따고 알려 줍니다.
  - 폴더 작업은 장마다 여유가 800MB 이상이 될 때까지 기다렸다가 처리합니다 (느려지더라도 멈추지 않게).
- **"메모리가 부족해…" 알림이 자주 뜬다**: Windows 가상 메모리(페이지 파일)를 늘리면 해결됩니다. *설정 › 시스템 › 정보 › 고급 시스템 설정 › 성능 설정 › 고급 › 가상 메모리 변경* 에서 **"모든 드라이브에 대한 페이징 파일 크기 자동 관리"** 를 켜고(또는 16GB 이상으로 지정) 재부팅하세요. 또는 사진 누끼 때 큰 프로그램을 닫아 주세요.

## 폴더 구성

```
start.bat          실행기
assets/            프로그램 아이콘 (바탕화면 바로가기용)
server/            AI 서버 (Python)
  app.py           로컬 서버 · 작업 큐
  batch.py         폴더 작업 (폴더 읽기 · 한 장씩 처리 · 결과 저장)
  render.py        폴더 작업 합성 (외곽선 · 배경 · 배치 · 저장 형식)
  lowmem.py        메모리 절약 모드 (변형 합성곱을 나눠 계산)
  assetcut.py      단색 배경 누끼 엔진 (종류별 객체 보호 · 배경 곡면 · 경계 투명도)
  matting.py       사진 누끼 엔진 (BiRefNet 추론 · 정밀 분석 · 메모리 단계)
  heavy.py         무거운 작업을 한 번에 하나씩
  models/          내려받은 AI 모델 (사진 973MB, 인물 973MB, 도우미 178MB, 빠름 224MB)
web/               편집기 화면 (React + WebGL)
  src/gl/          GPU 렌더링 (색 보정·마스크·합성 셰이더)
  src/components/  화면 구성 요소
.venv/             Python 실행 환경 (자동 생성)
```

## 개발자용

화면을 고치면서 바로 확인하려면:

```bat
.venv\Scripts\python.exe server\app.py --no-window
cd web && npm run dev
```

`http://localhost:5173` 에서 열립니다(API 는 8765 포트의 서버로 전달). 수정 후 `npm run build` 하면 `start.bat` 실행 시 반영됩니다.

### 참고
- GTX 1660 SUPER(6GB)에서 측정: 1024px 추론 1회 약 1.9초, VRAM 약 5.3GB. FP16 변환 모델은 정확도는 같지만 이 GPU(텐서 코어 없음)에서 2.8배 느렸고, cuDNN `EXHAUSTIVE`/`HEURISTIC` 알고리즘 탐색은 실행 오류가 나서 `DEFAULT` 를 유지합니다.

- AI 모델: [BiRefNet](https://github.com/ZhengPeng7/BiRefNet) (MIT 라이선스, 상업적 이용 가능)
- 배경색 번짐 제거: *Approximate Fast Foreground Colour Estimation* (Forte & Pitié, 2021)
